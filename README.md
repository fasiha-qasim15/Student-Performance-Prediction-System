# Student Performance Prediction System

## Project Description

Student Performance Prediction System is an AI-based Android mini application that predicts student academic performance using a machine learning model and TensorFlow Lite.

## Performance Categories

- Low Performance
- Average Performance
- Good Performance

## Technologies Used

- Python
- TensorFlow
- TensorFlow Lite
- Android Studio
- Java or the actual Android programming language used
- Git and GitHub

## Input Features

The application uses academic information such as:

- Attendance Percentage
- Study Hours
- Previous Exam Marks
- Assignment Marks
- Quiz Marks

## Project Requirements

- Windows or another supported operating system
- Android Studio
- Python environment for model training
- Git
- Android device or emulator

## Installation and Execution

1. Clone or download the project repository.
2. Open the Android project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Check that the TensorFlow Lite model is included in the correct assets directory.
5. Connect an Android device or start an emulator.
6. Build and run the application.

## Model Information

The machine learning model is trained using Python and converted into TensorFlow Lite format for Android deployment.
